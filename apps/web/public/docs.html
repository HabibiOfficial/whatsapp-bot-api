📖 API Documentation

REST API gateway hosted on Vercel. Worker bot WhatsApp jalan terpisah (Pterodactyl/VPS) dan komunikasi via Postgres.

Otentikasi: setiap endpoint /api/messages/* butuh header x-api-key: wba_xxxxxxxx. API key dibuat dari dashboard bot (login admin).

Base URL

https://YOUR-PROJECT.vercel.app

Authentication

Kirim API key di header x-api-key (atau query ?apikey=... untuk debugging):

curl -H "x-api-key: wba_xxxxxxxxxxxxxxxx" https://YOUR-PROJECT.vercel.app/api/health

Public Endpoints

GET /api/health

Health check Vercel function. Tidak perlu auth.

{"ok": true, "service": "whatsapp-bot-api-web", "ts": 1730212345678}

GET /api/status

Status koneksi bot (dibaca dari Postgres, tidak perlu auth).

{
  "bot": "connected",
  "connected": true,
  "user": {"jid": "6281234567890@s.whatsapp.net", "name": "WinaBot"},
  "updated_at": "2026-04-29T02:00:00Z"
}

Messaging Endpoints

POST /api/messages/send-text

Kirim pesan teks. Sinkron — function akan menunggu sampai bot benar-benar mengirim (max 8 detik), atau balik 202 kalau timeout.

BodyTypeRequiredNote
tostring✓Nomor (62...) atau JID lengkap
messagestring✓Isi pesan
curl -X POST https://YOUR-PROJECT.vercel.app/api/messages/send-text \
  -H "Content-Type: application/json" \
  -H "x-api-key: wba_xxxx" \
  -d '{"to": "6281234567890", "message": "Halo!"}'

# 200 OK
{"ok": true, "message_id": 42, "status": "sent", "to": "6281234567890@s.whatsapp.net"}

POST /api/messages/broadcast

Kirim ke banyak penerima sekaligus. Asynchronous — return 202 segera, bot akan proses di background.

curl -X POST https://YOUR-PROJECT.vercel.app/api/messages/broadcast \
  -H "Content-Type: application/json" \
  -H "x-api-key: wba_xxxx" \
  -d '{
    "to": ["6281111", "6282222", "6283333"],
    "message": "Halo semua!"
  }'

# 202 Accepted
{
  "accepted": true,
  "queued_count": 3,
  "skipped_count": 0,
  "queued": [
    {"to": "6281111@s.whatsapp.net", "message_id": 100},
    {"to": "6282222@s.whatsapp.net", "message_id": 101},
    {"to": "6283333@s.whatsapp.net", "message_id": 102}
  ]
}

GET /api/messages/:id

Cek status delivery satu pesan.

curl -H "x-api-key: wba_xxxx" https://YOUR-PROJECT.vercel.app/api/messages/42

{
  "id": 42, "jid": "6281234567890@s.whatsapp.net", "type": "text",
  "status": "sent", "error": null,
  "created_at": "...", "processed_at": "..."
}

Status Codes

CodeArti
200Sukses, pesan terkirim
202Diterima, masih di-queue / di-proses
400Body tidak valid
401API key tidak ada / invalid
403API key disabled
404Resource tidak ditemukan
429Rate limit terlampaui
502Bot gagal kirim (mis. nomor invalid)
503Bot tidak terkoneksi WhatsApp

Rate Limits

Per API key, default 60 request/menit (bisa diatur per-key dari dashboard bot). Saat over-limit, response 429.
