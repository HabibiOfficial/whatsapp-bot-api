REST API gateway untuk kirim pesan WhatsApp via API key. Self-host bot-nya, deploy gateway di Vercel.

Fitur

📤 Send Message

Kirim teks, gambar, dokumen ke nomor WhatsApp via REST API.

📡 Broadcast

Kirim pesan ke banyak penerima sekaligus dengan delay otomatis.

🔑 API Key

Setiap key punya rate limit sendiri. Kelola dari dashboard bot.

📊 Status & Logs

Cek status koneksi WA dan riwayat pesan langsung dari API.

🤖 Auto-Reply

Pattern matching (contains/exact/startsWith/regex) di sisi bot.

⚡ Async Worker

Vercel queue ke Postgres → bot polling, kirim WA, status sync.

Quick Start

Setelah API key kamu didaftarkan di dashboard bot, kirim pesan WhatsApp sesimpel ini:

curl -X POST https://YOUR-PROJECT.vercel.app/api/messages/send-text \
  -H "Content-Type: application/json" \
  -H "x-api-key: wba_xxxxxxxxxxxx" \
  -d '{"to": "6281234567890", "message": "Halo dari API!"}'
